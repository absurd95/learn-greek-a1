# Ελληνικά · A1

Небольшой офлайн-тренажёр греческого языка. Работает как обычный статический сайт и как устанавливаемое PWA.

Если вы хотите поручить ИИ добавить собственные слова, другой язык или новые режимы обучения, передайте ему файл [`AI_INSTRUCTIONS.md`](AI_INSTRUCTIONS.md). В нём описаны структура данных, правила против дублей, спряжения, тесты, офлайн-кэш и обязательные проверки.

## Словарь

Данные разделены по файлам в `data/`:

- `words.json` — слова;
- `verbs.json` — глаголы;
- `adverbs.json` — наречия;
- `phrases.json` — фразы;
- `professions.json` — профессии;
- `nationalities.json` — национальности;
- `months.json` — месяцы;
- `weekdays.json` — дни недели;
- `conjugations.json` — таблицы спряжений.

Раздел «Грамматика» — одностраничный справочник с поиском, примерами, произношением и тематическими тестами. Учебные схемы хранятся в `assets/grammar/` и доступны офлайн.

У каждой карточки должен быть постоянный уникальный `id`. Поле `new: true` добавляет её в раздел «Новые». При загрузке следующей партии смените флаг прежней партии на `false`; копировать карточки в отдельный файл не требуется.

## Локальный запуск

Из корня проекта запустите любой статический HTTP-сервер, например:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. Открытие `index.html` напрямую не поддерживается, потому что словари загружаются отдельными файлами.

## GitHub Pages

В репозитории откройте **Settings → Pages**, выберите **Deploy from a branch**, затем ветку `main` и папку `/ (root)`. Все пути в приложении относительные, поэтому оно будет работать по адресу `https://absurd95.github.io/learn-greek-a1/`.

## Артикли, род и ударение

На главном экране доступны две отдельные игры:

- **Артикли и род:** выбор ο / η / το (во множественном — οι / τα) для одного слова либо поле из 10 слов заданного рода. Можно выбрать число, темы, ошибки или ещё не тренировавшиеся формы.
- **Ударение:** слово показывается без знака ударения; нажмите на нужную гласную. Правильное написание, перевод и озвучивание доступны после ответа. Проверенные формы родительного падежа включаются отдельной настройкой.

Кнопки доступны с клавиатуры через Tab и Enter / пробел. Прогресс игр и сессия продолжения хранятся отдельно от результатов тестов перевода. Все игры работают офлайн после первой загрузки PWA.

Существительные содержат проверенные `nounForms` без артиклей. Неоднозначные слова общего рода исключаются из игры на род. Подробные правила добавления форм приведены в `AI_INSTRUCTIONS.md`.

Проверки перед выпуском:

```sh
python3 scripts/validate_data.py
node scripts/test_games.js
node scripts/test_verb_sets.js
```
